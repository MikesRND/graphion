# User guide

Learn to write processing blocks, connect them into models and control when they
run. The examples introduce configuration, state and data ownership as you build
from a single block to a composed model.

1. [Write a block](writing-blocks.md): configuration, ports and history.
2. [Compose a model](composing-models.md): children, wiring, build and call order.
3. [Manage data](managing-data.md): borrowing, retention and buffer reuse.

Start with the [quick start](../quickstart.md) if you want one complete Gain.
Detailed feedback and rate-conversion cases remain in the
[reference examples](../reference/examples.md).

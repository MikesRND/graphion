# Graphion documentation

Graphion composes processing models with declarative interfaces, explicit
execution and stated storage lifetimes.

- [Quick start](quickstart.md): write and run a small block.
- [User guide](guide/index.md): build blocks, compose models and manage data.
- [Programming reference](reference/index.md): exact API behavior and detailed rules.

For project principles and architecture, see the [charter](CHARTER.md)
and [design](DESIGN.md).
Current package availability is recorded in the [README](../README.md).

The [Model Semantics](model-semantics.md) defines the approved modeling terms,
rules, and acceptance examples. The Programming Reference defines the concrete
NumPy API and storage contract.
